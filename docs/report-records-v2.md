# Report records v2

The public `expand_report_records` reader accepts both `flowspec.report.records.v1` and `flowspec.report.records.v2`. V2 retains an acyclic node/shape table with compact numeric tags (`[-1, child...]` for arrays and `[shape_id, child...]` for objects). Graph tables remain in their original authority slot; an attempted additional graph interning enlarged ordinary reports and was not retained. V2 scalar strings beginning with `~` are escaped by an extra `~`; exact lowercase 64-hex `sha256:` strings use `~` followed by their hex payload. Expansion validates these forms and restores every byte. V1 keeps its original unwrapped graph slot and literal scalar strings. Unknown versions, malformed wrappers and invalid references fail closed.

Report ABI remains v1. All seventeen authority keys, fourteen identity inputs, legacy sections, graph tables v1/v2 readers, findings, losses, state and source ranges survive full expansion. Producer expansion equality is required before emitting packed bytes. The original byte and source ratio guards are unchanged. A new consumer must expand report records before reading graph tables, as the public typed Manifest reader does. This changed wire version requires independent affected consumer judgment; source tests do not admit the migration or qualify launch.
