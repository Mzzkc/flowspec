# Lossless graph tables v2

This developmental representation migration preserves report ABI v1. It is not release qualification. The public reader is `flowspec::commands::expand_graph_tables`; it accepts both `flowspec.graph.tables.v1` and `flowspec.graph.tables.v2`. All ordinary library, CLI JSON and YAML reports use the same normalizer. The existing fourteen identity inputs and seventeen serialized authority fields are retained. Graph wire representation is itself an identity input; changing its bytes changes report identity without changing binding or finding identity.

V2 retains the v1 language, name and kind dictionaries. Each path dictionary entry is its exact UTF-8 path string, or `["hex", original_hex_path_key]` for a non-UTF-8 POSIX path. Each entity row is `[path_index, language_index, name_index, kind_index, start_byte, end_byte, start_line, start_column, end_line, end_column]`. It retains all six original range coordinates rather than deriving them from unavailable source. V1's names remain `[path_relative_boolean, name]`; path-relative names reconstruct the exact `path::name`. Stable binding and edge keys are recomputed using the unchanged canonical algorithm.

Dependency edge rows, boundary edge indices and type-flow records are unchanged. A single-edge call flow whose two nodes exactly match that edge's source and target may be stored as the integer edge index. Other flow rows retain the v1 ordered `[node_indices, edge_indices]` form. The decoder reconstructs complete ordered paths and all stable keys. Compatibility loss/state references continue to point to `/authority/losses` and `/authority/pattern_state`. No finding, loss, inventory, graph entity, range or edge is removed. The normalizer verifies byte-for-byte decoded graph equality before installing the representation.

Readers that recognize only v1 need to adopt the named public reader before consuming v2. Original byte bounds and independent migration review remain required; this representation does not assert that the entire report fits them.
